How it works

  1. Photo resized to 224 × 224 px, ImageNet normalisation applied
  2. MobileNetV2 neural network (2.3M params) runs on-device via WebAssembly
  3. Softmax outputs per-class probabilities — top class is the prediction
  4. Confidence < 60% triggers a retake prompt for the farmer
